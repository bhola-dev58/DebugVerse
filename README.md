Clone the project to your Local machine
```bash
git clone https://github.com/bhola-dev58/DebugVerse.git
```
# How to run the project

RUN Backend 
```
cd backend
uvicorn main:app --reload
```

To Run frontend
```bash
cd frontend
```
**Install depandencies**
```bash
npm install
```
Run this command to run the project
```bash
npm start
```
